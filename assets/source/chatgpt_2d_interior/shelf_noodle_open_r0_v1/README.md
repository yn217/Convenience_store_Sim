# カップ麺棚（日本のコンビニ／開放型・屋根なし）初期2Dアセット

PNG（RGBA相当の透明パレット）とSVGをEMPTY/HALF/FULLで**各1ファイルずつ**登録。

- 日本のコンビニ用常温ゴンドラを意図。**巨大天板・上部ボックス・天蓋を一切持たない**。
- 商品は台形の紙カップ容器・楕円状の蓋と、色違いの紙ラベルで表現する。立方体包装は禁止。
- 棚板、細い前後支柱、底座は状態間共通。棚の投影は`IsoProjection` 2:1、初期想定サイズ1m×2m、z1.73m。
- 原画SVGが構造基準。PNGはベクター座標を同一レンダラでラスタ化した**画質・幾何未承認のラフ**。透明色はアルファ0、通常画素は255。
- 絵の実測ピクセルから`ground anchor`とpaddingが確定していない。**既存roof付きshelf_general EMPTYのalpha bboxをコピーしない**。
- Godot runtimeへの登録、縮尺/画角/商品カテゴリの独立Visual QAは未実施。ユーザー承認まで`runtime_approved:false`。
- 既存の常温ゴンドラの`FULL/HALF/EMPTY`完成画像を基準に、商品だけ変える最終的な製造方法をCodex側で検討する。
- ImageGenが出力した店舗什器一覧アトラスは本フォルダの**単体素材と別**。アトラス原本のGitHub登録は本コミットに含まない（今後の参考資料）。
