## 旧失敗との違い
PR #161の「屋根付き正規EMPTYに合わせる」「Keep the cap / empty top canopy / white top cap」という誤指示を採用しない。商品上部を覆う大面積屋根は描かない。薄い販売用棚板・支柱・レールだけにする。同じSVG作成方法から3状態を派生し、棚構造が状態間で変わらないようにした。商品表現は可読性調整が必要な簡易イラストであり、実在パッケージの精密再現は主目的ではない。

## Codexの次の仕事
1. 実際の日本のコンビニ開放型ゴンドラ参考画像とユーザーモックアップに対し、EMPTY棚形状を先に独立レビュー。**未合格ならFULL/HALFを採用・量産しない**。
2. SVGの幾何・世界座標投影は設計値であり、旧PNG `canvas 442×449 / anchor(285,302)` への一致を保証していない。**旧bboxへ強制変形せず**、正規2x RGBA PNG + manifest + ground-anchorを作る。今回の短辺校正は投影面での画像伸縮ではなく、iso2xのワールドX方向だけを0.92mの設置外形へ合わせ、接地点を固定した小補正。
3. 顧客がアクセスするE側が正しいか、最上段の天面が商品を遮らないか、z=0接地と実ゲームにおける足元・縮尺・角度を確認。
4. `#157 / #102 / #123` のReference QA→構造→投影→独立Visual QAを満たしてから候補採用。
5. ImageGenから生成した「店内アセット一覧アトラス」は比較アイデアであり、背景/文字入り画像をそのままGodotスプライトにしない。ゲーム画像は各素材ごとに分け、実runtimeは事前合成の1スプライト。
