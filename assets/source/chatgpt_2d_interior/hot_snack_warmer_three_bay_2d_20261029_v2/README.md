# ホットスナック3区画ケース（2D再制作版）

レジ横に置く日本のコンビニ用3区画保温ショーケース。からあげ・コロッケ・肉まんをガラス越しに見せる一体型の2Dベクター原画です。

この画像はImageGenが誤って返したデザート一覧画像ではありません。独立に描画したゲーム用SVG、縮小透過PNG、ZIPです。旧 `hot_snack_warmer_three_bay_chatgpt_20261029_v1` の原画やハッシュを上書きしません。

元データを保持し、Godotで `iso2x_v1` と `r0` の方向、床接地、設置タイル、ガラス透過と商品読取性を検証すること。現在は `runtime_approved:false`。画像の解像度は設備のゲーム性能グレードとは無関係。PRはDraft、mainにはマージしないこと。
