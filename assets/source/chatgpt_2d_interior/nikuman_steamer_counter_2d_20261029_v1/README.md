# C03：肉まん蒸し器 2D（レビュー専用）

日本のコンビニのレジ横にある小型ガラス蒸し器を独立アセットにしました。2Dベクター原画、透過PNGの512/256プレビュー、肉まんを外したEMPTY派生原画／画像を収録。3段×2列奥行×4個＝24個の肉まんを描いています。ImageGenが出力した飲料ケース一覧画像は誤生成で、**含めていません**。

## 必須QA
- 正式な `iso2x_v1` 正投影・回転方位・顧客アクセス側をGodotゲームで照合。図の座標は**art local units**でありworld寸法は未定です。
- r0の顧客アクセス、接地pivot、設置タイルは設計未確定。画像を縦横別々に拡縮せず、まず寸法/投影を決めてください。
- FULL/EMPTYは共通のガラス・棚・筐体。焼き込んだ商品の販売在庫との同期を追加するまでruntimeでは使用禁止（#168）。
- ガラス透過、縁のalpha、ゲーム実ズーム、実写真との照合と独立Visual QA、ユーザー目視承認が必要。
- `runtime_approved:false`。Draft PR #164のまま、mainに無断merge禁止。
