すべて**棚1台だけの独立2D透過素材**。棚の前縁を奥より約0.095m低くした4段の傾斜トレー。大きな屋根/トップキャップなし。商品は立方体パッケージにせず、透明フィルム風の袋に入った菓子パン/惣菜パンを2Dの輪郭で表現。棚板・支柱・レール位置は3状態で共通。表示上の向きと占有寸法は既存`iso2x_v1`の2x投影式に準拠。アセットの最終校正は未実施。

## 未合格項目と指示
1. **日本のコンビニ棚の現物の写真**（パンの斜め陳列・棚札など）とユーザーモックアップの棚を照合。什器形式が違えば採用せず再設計。
2. `EMPTY`の形状を先にレビュー。最上販売段に巨大な屋根を描いていないこと。
3. `FULL/HALF/EMPTY`で棚本体ジオメトリ固定を確認。商品だけ状態差分。
4. Codexが1×2m占有world basis、ground anchor、最上段高さ、投影方向`r0`、ズームを実Godot画像に重ね検証。新旧pngシルエット一致を要求しない。
5. 2Dの包装イラストは**商用品質未達の試作**。商品柄・形状・密度、透明縁、影、輝度を調整する。生成数だけで承認扱いにしない。
6. `runtime_approved:false`、ユーザー承認までDraftを維持。
