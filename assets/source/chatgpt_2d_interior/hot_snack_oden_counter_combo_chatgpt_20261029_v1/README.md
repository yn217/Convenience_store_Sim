# ホットスナック＋おでんの複合加温ケース / FULL / 未採用

日本のコンビニのからあげ・フライドチキン・コロッケと、おでん・肉まん等を陳列した**2区画連結型の大型ケース**。単一の小型レジ横ケースではないため、将来の設備グレードとして別IDで管理する。

- `source_original.png`: ChatGPT生成原画1536×1024（変更なし）
- `source_fullres.webp`: 原寸・高品質圧縮版
- `game_512.png` / `game_256.png`: **同一設備の描画LOD**（ゲーム内の設備性能差とは別）
- `manifest.json`: 商品分類、透過処理状態、投影ルール、承認状態
- 外観は3D風にレンダリングされた**静止2D画像**。3Dメッシュ・実体アセットではない

**Codex要実装**: `iso2x_v1`実ゲーム画面との比較、r0/+X側の販売面、グリッドでの大型占有サイズ、接地座標、ガラス部のアルファ/フリンジ、ユーザーのUI・設置/衝突/選択判定をQAする。斜めの長辺向きはゲームの既存r0方向と異なる可能性がある。鏡像反転で日本語ラベルを壊さず、必要ならChatGPTに投影ガイド付きで再生成を依頼する。単一卓上ケースを別途制作するまでこの画像を代用・正式採用しない。

正式承認まで `runtime_approved:false`、mainへマージ禁止。
