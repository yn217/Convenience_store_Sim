# 車の投影ガイド再生成 v2

2:1投影の1.65m×3.8m×1.45mガイドとv1原画を参照し、内蔵image_genで1回再生成した。透明RGBA原画を保持。

短辺の屋根前縁は+0.478、下部サイドシル長辺は-0.499で許容目安内。一方、屋根の近側長辺は-0.578、遠側長辺は-0.546で、平行性を満たしていない。測定は画面上の直線に近い縁の手動端点で、精密な形状計測ではない。

**判定：実配置QA候補。** 屋根は曲面であるため、全シルエットの平行性だけでは不採用とせず、下部車体の地面軸・駐車枠との整合・接地を実画面で確認して最終採否を決める。v1候補は保存する。v2を別IDで梱包し、Rendererは変更しない。上記の屋根誤差は制約として保持する。

次案はガイドに沿う決定論的な2D輪郭・車体面を先に確定し、その形状を保つ材質画像を作るか、ユーザーの合意を得て許容角度を再定義する。非均等変形による帳尻合わせは行っていない。
