# Issue #91 beverage label-art candidates

Three original, text-free fictional package-art textures used on the Blender-rendered 500ml drink models in the Issue #91 fridge candidate. The generated artwork is not a final SKU identity and is not runtime-approved.

- `green_tea/label_art_v01.png`: deep green and cream tea leaves with restrained gold motifs.
- `citrus_soda/label_art_v01.png`: citrus slices, leaves, and bright orange/yellow palette.
- `unsweetened_coffee/label_art_v01.png`: espresso brown, coffee leaves/beans, and antique-gold details.

Each `prompt.txt` records the requested content. The textures were created with OpenAI ImageGen for this repository task on 2026-10-24, then UV-mapped in Blender on the modeled bottle label band. They contain no third-party source images, readable copy, or real-world brand marks. Generated-image usage rights and the applicable OpenAI terms must still be reviewed before any commercial release.

The companion `issue91_beverage_packshots_v01` are visual concepts only; their soft alpha glow makes them unsuitable as direct in-game sprites.
