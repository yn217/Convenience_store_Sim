# Cup-noodle package wrap-art candidates

Two original, text-free generated flat wrap textures for physically modeled 110 × 110 × 120mm cup-noodle products:

- spicy_miso/label_art.png: warm red/orange, spicy-miso food illustration.
- seafood_soy/label_art.png: deep blue/teal, seafood and noodle illustration.

Both are 1774 × 887 RGB PNGs (2:1). Each has its own prompt and provenance/license note. Created with built-in Codex ImageGen on 2026-10-24; model/version metadata was not exposed. No third-party source image or brand was used. The textures have been UV-mapped for the candidate Blender noodle shelf but still require seam/zoom/runtime visual acceptance.
