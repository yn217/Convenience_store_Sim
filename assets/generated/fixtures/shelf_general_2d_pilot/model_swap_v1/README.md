## 投影ガイドと工程

canonical は `assets/generated/fixtures/shelf_general/shelf_general_0_body.png`。r0のメタデータは同ディレクトリの `shelf_general_a.visual.json`。442×449px、anchor [285,302]、footprint 1×2、iso2x_v1。新しいスプライトでも同じキャンバスとanchorを比較基準とした。canonicalのファイル名自体にはemptyの語はないが、表示を確認し、商品が載っていない棚本体を投影ガイドとした。

生成はすべて内蔵image_gen。3Dモデルや3Dレンダラーは使わず、棚と商品を一度に描いた。画像生成後の処理は、RGBA原本からの一様縮尺と平行移動によるキャンバスへの配置のみ。縦横別の縮尺、回転、遠近変形、商品カードの後貼り、透明部分の描き直しはしていない。原本のalphaを保持した。

1. `a_initial_raw.png`: 商品量と棚への接地は得られたが、文字と細密な包装表現が多い。
2. `a_refined_raw.png`: 文字をなくし単純化。ただし高さを合わせると幅が26px短い。`comparison.png` と `qa_metrics.json` にこの途中結果を保全。
3. `b_generated_raw.png`: 初回の問題をプロンプトに反映。淡色・丸い袋の構成。外接範囲がcanonicalと一致。
4. `a_final_raw.png`: Bを編集対象、canonicalを投影ガイド、A途中案を商品配色だけの参照にして再生成。幅差を4pxに縮小し、包装表現も簡素化。

正確な全プロンプトは `prompts_complete.json` を参照。`prompts.json`、`prompt_b.json`、`prompt_a_final.json` は生成中に保存した引数スナップショットで一部のpromptフィールドを欠くため、再生成には完全版を使う。`prompts_completed_rounds.json` は最終A以前の完全プロンプト。

最終値と配置の一様縮尺係数は `qa_metrics_v2.json`。角度は長い負勾配エッジをHough検出した加重中央値で、各棚板の精密な対応点測定ではない。IoUは空棚の外形との比較で商品や穴の違いも含む。彩度proxyは天板も分母に含み、白いパン袋を商品として数え切れないため、商品の実面積率とは区別する。

原本・等倍比較・輪郭重ね合わせを目視確認。四段の長辺の商品列は棚の縁に接地し、隣の商品と接している。浮いたカードの列や箱の側面を並べる表現は避けられている。両案とも2Dイラストだが、袋のふくらみと棚の奥行きを示す陰影は残る。天板はcanonicalの形状維持を優先し、面積を削っていない。

残差: Aは幅が4px短く、両案とも角度に約0.2°差があるため、厳密な完全一致を保証する候補ではない。短辺側の最下段に棚板の空白が残る。背面はこのr0で隠れるため、両面ゴンドラの裏面陳列や別回転は未検証。完成した透過スプライト候補として保存し、runtime採用はしていない。

検証はこの画像の寸法・alpha・投影比較と目視のみ。フルテストは実行していない。

## 再計測

`package_and_qa.py` は新規ファイルのみ作成し、同名ファイルがある場合は停止する。最終ラウンドの引数は `a_final_raw.png _v2`。同じディレクトリでの再実行は既存ファイル保護のため停止する。新しいsuffixを指定すれば別名で再計測できる。

`SHA256SUMS_v2.json` は最終画像作成時点のハッシュ記録。最後に追加した説明・manifestまで含む一覧は `DELIVERY_SHA256.json`。画像生成原本もすべて保全している。
