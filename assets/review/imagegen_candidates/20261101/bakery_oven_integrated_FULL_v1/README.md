# Bakery oven/display — review candidate

Single bakery fixture candidate for MVP `bakery_oven`: upper heated glass bread display with three stocked shelves and an integrated lower oven/service cabinet. The original source PNG is unchanged. Padding and checkerboard images are QA-only derivatives and are not resampled.

Nominal fixture contract is 1x2 tiles, 0.92 x 1.92 x 1.60m, access E. Exact world fit, axis calibration and ground anchor remain unverified. Do not stretch non-uniformly to fit.
