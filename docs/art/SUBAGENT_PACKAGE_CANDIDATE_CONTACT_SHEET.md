# Subagent package candidate contact sheet

`subagent_package_candidate_contact_sheet_v01.png` is a review-only visual index of representative generated package candidates.

It is not a runtime atlas and does not change SKU, slot, inventory, LOD, or visual manifest data. Candidates remain `runtime_approved: false` until human review and iso2x/anchor/runtime validation are complete.

Build locally with:

```text
python tools/art/build_subagent_package_contact_sheet.py
```
