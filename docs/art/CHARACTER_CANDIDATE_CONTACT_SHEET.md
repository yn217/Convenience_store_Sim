# Character candidate contact sheet

`subagent_character_candidate_contact_sheet_v01.png` is a review-only comparison of four normal-pose and four clean action candidates.

It is not a runtime sprite sheet. Four-direction rendering, animation states, normalized height/anchor, occlusion and Godot integration remain open; all candidates stay `runtime_approved: false`.

Build locally with:

```text
python tools/art/build_character_candidate_contact_sheet.py
```
