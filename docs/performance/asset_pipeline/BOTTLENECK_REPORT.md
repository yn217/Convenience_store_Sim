4. ケース当たり総時間、成功率、失敗率、最終採用までの時間、実際の人手時間、並列化speedupは算定不能。

## 原因別リワーク

- **入力・構造の正しさ**: AのU→V→corner_v2は壁方向/コーナー整合を後から直した。Cはcanonicalとpromptが屋根を要求していたため、画像モデルではなく参照仕様が失敗を生んだ。最新STOPにより過去棚試作は形状Hard FAIL。
- **投影・画像処理**: Aでは生成後のshearが必要。Bの透明化編集は周辺ぼけを再導入し、key shaderへ戻した。Cでは薄いalphaノイズがbbox比を誤らせ、再生成を誘発した。
- **統合・QA**: A/Bで配置、入口向き、夜間shader、花壇干渉などの修正が複数発生。画像を再生成せずコード修正で解決したケースもある。実時間未計測。
- **成果物受渡し**: Aで追加生成画像の保存場所が確定できず親側再生成。再生成時間は観測できるが発見/受渡し時間不明。
- **並列の選択・依存**: HVAC二候補は同時生成。所要時間の合算は不可、候補選定理由も未記録。
