# UI/UX 再設計: 現行UIの分解と方針 (Issue #61)

更新: 2026-10-24。対象: `integration/m6-ui`(PR #81)。目標画像: 店舗が主役、UIは必要な時だけ出る日本の商用ゲーム風。

## 1. 現行UIの構成要素

| 領域 | 要素 | 常時表示 |
|---|---|---|
| 上部HUD (64px) | 所持金 / 本日の売上 / 粗利 / 店内客 / DAY・時刻 / 日付 / 速度表示 / 停止・×1・×2・×4 / 営業状態 | 常時 |
| 左ナビ (200px) | 店舗 / 商品 / スタッフ(無効) / 営業 / データ / 設定。押すと右インスペクタの該当カードへスクロールするだけ | 常時 |
| 建設パレット (280px) | 什器10種(サムネイル・価格・サイズ)、元に戻す/やり直す、操作ヒント、配置プレビュー文、状態文 | 常時 |
| 店舗ビュー | 店舗・客・看板・光、浮遊カード(低在庫・イベント)、トースト、売上ポップ | 常時 |
| 右インスペクタ (320px, 縦スクロール) | インスペクタ(選択・移動/回転/撤去) / 今日のイベント / 選択中の什器 / 演出・音 / 表示モード / 営業・明日の広告 / 在庫・発注 / 販売価格(24行) / 日次レポート / セーブ・ロード / はじめかた・目標 | 常時(11枚のカード) |
| 下部 (約120px) | よく使うコマンド(タブ+6ボタン)+ 移動/回転/撤去/表示切替、指標カード4枚 | 常時 |

1920×1080 で店舗ビューは約 1120×890px(全体の約48%)。

## 2. モードごとに本当に必要なもの

| モード | 必要 | 不要 |
|---|---|---|
| 通常営業 | HUD(時刻・季節・お金・売上・粗利・来店・営業状態・速度)、細い機能メニュー、小さなサマリー、短い通知 | 建設パレット、右インスペクタ全体、コマンド群、設定類 |
| 建設 | 什器カタログ(カテゴリ・大きめサムネイル)、配置プレビュー、回転/取消/やり直し、資金 | 右インスペクタ、分析情報 |
| 什器選択 | 什器名・カテゴリ・サイズ・価格・在庫/陳列・商品設定・価格・移動/回転/撤去 | 建設カタログ、店全体の分析 |
| 経営・分析 | 発注/在庫、価格表、広告、営業開始/閉店、目標、日次レポート、セーブ、設定 | 建設カタログ |

## 3. 削る常設UI
- 建設パレットの常設 → 建設モード時のみ。
- 右インスペクタの常設 → 什器/客の選択時のみ。中身は選択に関係するカードだけ。
- 下部「よく使うコマンド」と移動/回転/撤去バー → 削除(左メニューと選択インスペクタに集約)。
- 演出・音、表示モード、セーブ/ロード → 設定画面へ(表示モードはHUDの小さな切替+Oキーを残す)。

## 4. 専用画面へまとめる要素
- 商品: 在庫・発注、販売価格
- 経営: 営業開始/閉店、明日の広告、今日のイベント、はじめかた・目標
- データ: 日次レポート、実績
- 設定: 演出・音、表示モード説明、セーブ/ロード
専用画面は店舗の上に開くタブ付きウィンドウ(閉じると通常に戻る)。営業開始/閉店はHUDの営業状態ボタンからも操作できるようにする。

## 5. 画面構成と状態遷移
```
通常 ──[店舗/建設 or B]──> 建設 ──[Esc/閉じる]──> 通常
通常 ──[什器/客をクリック]──> 選択 ──[Esc/空き床クリック/閉じる]──> 通常
通常/選択 ──[商品・経営・データ・設定]──> 画面(タブ) ──[Esc/閉じる]──> 直前のモード
建設中に什器をクリック → 配置操作を優先(選択インスペクタは出さない)
```
- 通常: 上部HUD、左の細いアイコンメニュー(72px、ラベル付き)、下部の小さなサマリー(高さ約64px)、トースト。
- 建設: 左にカタログ(カテゴリタブ+2〜3列のカード)、店舗上に配置プレビュー。
- 選択: 右にインスペクタ(閉じるボタン付き)。
- 画面: 中央に大きめのウィンドウ(店舗は暗く透ける)。

## 6. Phase 1 で変えること
1. `UiMode`(通常/建設/選択/画面)を MainLayout に導入し、表示を切り替える。
2. 建設パレットを通常時は隠す(建設モードで表示)。
3. 右インスペクタを未選択時は閉じ、選択時は選択関連カードだけを出す。
4. 選択以外のカードを専用画面(タブ付きウィンドウ)へ移す。
5. 下部のコマンド群を削除し、サマリーを小型化。
6. 左ナビを細いアイコンメニューにし、各ボタンでモード/画面を開く。
7. 店舗ビューの面積を通常時に約80%以上へ。
