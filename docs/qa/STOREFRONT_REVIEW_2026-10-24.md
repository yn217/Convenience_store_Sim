# 店舗外観・カメラ・GUI レビュー (2026-10-24)

入力: `convenience_ui_storefront_review_package.zip`(pairs / crops / 補助モックアップ)。基準: main 1bfe346。

## 1. 差分
### GUI
- top bar: 構成は目標とほぼ同じ。目標は値の文字が大きく、グループの区切りと背景の透け感で一体の帯に見える。現状は小さなチップが離れて並び、帯の右側に空きがある。
- left nav: 目標はアイコンが大きく、選択中が明るいタイル。現状は細く小さい。
- bottom HUD: 目標は「目標 / KPI 5枚 / イベント」が1本の帯にまとまり、KPIアイコンが大きい。現状はカードが離れ、イベント欄は文字が切れる。
- build catalog / inspector: 目標は商品が入った什器の写真サムネイルと濃い情報密度。現状のサムネイルは空の棚。
### カメラ・店舗の大きさ
- 目標は店舗内部が画面の大半を占める。現状の初期表示は店全体+外周を収めるため、内部は画面の約3割、空き床と外の余白が多い。
### 外観・外構
- 目標: ガラス張りのファサード(窓・自動ドア・社名帯)、ポールサイン、駐車場(白線・車止め・車)、自転車ラック、ベンチ、ゴミ箱/リサイクル箱、のぼり、自販機、街路樹・植え込み・街灯、OPEN看板、店頭ポスター。
- 現状: 道路・歩道・暗い緑の面と小さな看板だけ。店は「壁を切り取った箱」に見え、中と外がつながっていない。
- 素材の状況: Codex #107 でガラス店頭(壁・窓・ドア)、桜、植え込み、OPEN看板、自転車ラック、植木鉢、POP、壁面冷蔵ケース、レジ背面セットは**main にあるがゲーム未接続**。自販機・ベンチ・ゴミ箱・のぼり・車止め・駐車場・ポールサイン・街灯・車は**素材なし**。
### 店内
- レジ周り: 目標はカウンター上の小物、背面の什器、店員、並ぶ客で密度が高い。現状はレジが小さく孤立。
- 棚密度: #91/#102(Codex作業中)。

## 3. カメラ案
- 初期ズーム: 「店舗の床が、HUD・左ナビ・下部HUDを除いた領域の 90〜100%」を基準にフィット(外周は画面外に出てよい)。
- 中心: 店の床の中心から入口側へ 1〜2 タイル寄せ、ファサードが画面下側に入るように。
- F キー: 現行の「全体フィット」は残し、別キーで「店内フィット」に切り替え(初期は店内フィット)。
- パン範囲: 外構を見られるよう、店の外へ数タイルまで。
