## 座標系
- JSON内`anchor_px`は**高精細コンセプト画像に対応する画素位置**。画像左上が`(0,0)`、東西南北を表す地理座標ではありません。サイズは**1672×941**です。
- スクロール/ズーム/レターボックスのない場合、画像上のピンは`(screen_x,screen_y) = (origin_x + anchor_x*scale,origin_y + anchor_y*scale)`。余白/パディング・パン・ズームは実装時に同じ変換を全ピンに適用してください。
- 画像内の距離・疑似等角カメラから、直接徒歩時間・メートル・道路距離を計算しない。**駅・道路グラフは別正本**が必要。
- 港や橋、地名の大まかな位置関係を検証するため、確認SVGを参照。実GIS座標に使いたければ別途出典/投影/現地資料から再制作すること。

## 地理的に守ること
1. 本州側の沿岸で西→東：**明石 → 舞子（明石海峡大橋） → 神戸中心部**。
2. 明石海峡大橋は**神戸市垂水区の舞子と淡路市岩屋**をつなぐ。対岸を三宮中心部へつなぎ直さない。
3. 六甲山系は神戸の内陸側、神戸空港は神戸港沖側。
4. 淡路島の北から**岩屋 → 淡路SA / 淡路夢舞台 → 洲本 → 南あわじ**。南は**鳴門海峡と四国方面**。
5. **淡路島内に鉄道・鉄道駅を配置しない**。岩屋は港/フェリー、洲本はバス停/生活中心。
