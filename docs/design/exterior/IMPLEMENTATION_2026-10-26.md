# 店舗外観の2D描画契約

2026年10月26日の作業は、`origin/main` の `77bac28` を基点とする。
元の作業フォルダーは古い `integration/m6-ui` であったため、専用worktreeへ分離した。
元フォルダーの未登録素材や他作業者の変更は取り込まず、そのまま保存している。

## 投影と配置

1タイルを1mとする2:1の直交投影を使う。
画面座標は `u = origin.x + zoom × 64 × (x-y)`、`v = origin.y + zoom × (32 × (x+y) - 78.38367177 × z)` で求める。
画像は2倍の制作解像度を持ち、全インスタンスで `zoom / 2` を適用する。
画像ごとの任意倍率や画面固定位置は使用しない。

`runtime_asset_catalog.json` は既存素材を含む寸法、アンカー、方向、描画グループの台帳である。
画像生成には誤差があるため、名目寸法と実測値を各素材の仕様と生成記録に分けて記す。
欠けている方向画像を引き伸ばして代用しない。
車は採用方向を南北の入口に限定し、東西向けのミラー画像は光の向きが異なるため使用しない。
円形に近い樹木だけは方向間で同じ画像を共用する。

## 建築と操作

遠側の壁は高さ2.6mを維持し、白いパネル、青帯、笠木、換気ルーバー、ガラス入口の枠を追加した。
手前の窓は高さ1.2mの既存カットアウェイを維持する。
正面上部の帯は独立した `FacadeCanopy` で描き、高さ2.28～2.78mの範囲に限定する。
画面全体を覆う画像や入力を受ける透明コントロールは追加しない。

店舗内へカーソルを入れた場合、床が選択されている場合、建築モードの場合には上部帯を隠す。
床の選択を解除して店舗外へカーソルを移すと帯を戻す。
切り欠きの変更は描画の可視性だけに作用し、衝突、客の経路、経済、保存形式を変更しない。
店名とポール看板の文字はフォントで描き、壁面に沿う `Transform2D` を適用する。

## 外構

入口側では店舗外周から0～2mを歩道、2～7mを駐車面、7.18m以遠を道路とする。
駐車区画は幅2.5m、奥行約4.8mで、沿方向に2.7m間隔で置く。
入口の手前に区画を作らず、歩道と道路を結ぶ通路を残す。
車長3.8mの車の中心は店舗から4.6mとし、車止めの外側へ収める。
旧来の真横向きの車と駐車タイルは使用しない。

白線、車止め、樹木の接地影はワールド座標の2Dポリゴンで描く。
これらの地面描画を先に行い、続いて既存の `rank` と `x+y` の順に画像を描く。
上部建築、地面、屋外設備の責務を分け、重なりの解決に大量のz-indexは使わない。
外構は寸法、入口、投影、viewportが変わったときだけ再構築し、毎フレームの画像処理は行わない。

## 制作の再現

生成は組み込み `image_gen` を使用した。
生成モデルの内部識別子とseedはツールから公開されていないため、推測した値を記録しない。
原画、プロンプト、投影ガイド、アンカー測定、誤差は各素材の `PROVENANCE.json` と仕様JSONへ保存する。
再梱包は `tools/assets/package_exterior_tree.py`、`package_exterior_planter.py`、`package_compact_car_painted.py` を使う。
これらは均等な縮小と透明キャンバスへの配置を行い、画像を斜めに引き伸ばさない。

生成画像の検査だけで採用完了とはしない。
実ゲームで接地、枠内への収まり、透明縁、商品への遮蔽を確認し、最終の見た目はユーザー確認に委ねる。
3D生成への切り替え、GitHub Actions追加、経済機能の追加は行っていない。

## 継続作業

現在の緑地には背景の単色面が残る。
境界フェンス、連続した生け垣、室外機、店頭ポスター、ガラスの開閉表現、方向別の車両と設備は後続の制作対象である。
棚、商品、人物は今回の範囲外であり、目標画像と画風が揃ったとは判定していない。
既定カメラは店舗内を優先するため、外構の全景と上部の樹冠は一部画面外になる。
この制約を隠すためにカメラの既定値やズーム下限を変更していない。

関連Issueは #110、#103、#111、#114である。
