# Issue #148 小春六花：出店場所選択モックアップ

駅前・学校前・オフィス街・住宅地の立地差を、来店時間帯・売れ筋・土地費用・難易度で比較する初期出店画面案です。

## 対象

- 抽象化した街の地図と4つの立地ピン
- 駅前、学校前、オフィス街、住宅地の比較カード
- 相対来店者数、時間帯別ピーク、売れ筋カテゴリ、土地費用、難易度
- 選択中の立地の来店時間グラフと特徴説明
- 「この立地で始める」導線と、開店後は店舗属性として保存する注記
- 小春六花を立地選択の案内役として配置

## 境界とデータ上の注意

- 静的なUIモックアップであり、地図、立地プロファイル、需要モデル、セーブ・ロード、出店処理には接続していません。
- 来店者数、土地費用、難易度、売れ筋は仕様検討用の相対・例示値です。実在の地図、GPS、実測データは使用していません。
- 実装時は立地IDを店舗の永続属性として保存し、時間帯・来店目的・カテゴリ嗜好・予算・寄り道係数の重複適用を避けてください。
- 女性や主婦などの固定的な属性で客層を表現せず、ゲーム内の抽象的な需要グループとして扱います。
