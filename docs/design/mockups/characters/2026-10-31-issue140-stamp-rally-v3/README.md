## 画面意図
- メインは既存ゲームと近い店舗俯瞰表示。特設売場、対象商品、スタンプ進捗、景品残数と交換操作をUIとして提案する。
- 濃紺HUD、左ナビ、下部バー、右側イベント操作パネルの整合を優先。小春六花はアシスタントとして補助的に表示。
- 画像はデザインレビュー用であり、ゲーム内スクリーンショット・動作画面ではない。画面内の数値や演出は仮データ。

## 実装に進む際の注意
- 景品在庫、交換条件、達成時の処理はIssue #140の台帳と状態に接続する。未達の条件で景品を消費しない。
- 複数商品の購入を前提とする施策は #128 が実装・検証されるまで見た目だけで先行実装しない。
- GUIと店舗を覆う情報表示の兼ね合い、1280×720・1600×900・1920×1080の可読性を実ブラウザ／Godotで別途検証する。
- このPRでは画像とドキュメントのみを追加し、既存のゲームロジック・アセットを変更しない。
