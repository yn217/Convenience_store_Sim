# Issue #138 小春六花：限定くじ管理モックアップ

架空の限定景品くじを、開催期間・券価格・賞別残数・セット在庫で管理する画面案です。

## 対象

- 架空企画「星空マスコットくじ」
- 開催期間、販売状態、1枚の価格
- A賞〜D賞の景品と有限残数
- 仕入れ価格、販売可能枚数、残り枚数、売切れ予測
- 「セットを仕入れる」「展示台を確認」の操作

## 境界と権利

- 静的なUIモックアップであり、抽選seed、景品配布、売上記帳、セーブ・ロードには接続していません。
- 景品はすべてゲーム内の架空商品です。実在作品、キャラクター、商標、くじ名称は使用していません。
- 数値、残数、開催期間、売切れ予測は画面検討用の例示値です。
- 小春六花の外見はユーザー提供の参照画像を基準にしています。製品同梱・公開配布前にキャラクター/IP利用条件と再配布可否を確認してください。
