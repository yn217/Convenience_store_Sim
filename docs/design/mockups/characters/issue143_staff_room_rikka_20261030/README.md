# Issue #143 小春六花：スタッフ管理・控え室モックアップ

小春六花がスタッフの休憩、担当、疲労度を案内するスタッフ管理画面の検討用モックアップです。

## 対象

- 控え室 M の容量 `4 / 6人`
- レジ担当・品出し担当・休憩中の人数
- スタッフごとの担当、疲労度、勤務状態
- 「休憩させる」「担当を変更」の操作位置

## 境界と権利

- 静的なUIモックアップであり、Godotの実行画面、疲労計算、担当変更、セーブ・ロードには接続していません。
- 容量、氏名、疲労度、配置、ボタン文言はIssue #143の画面検討用の例示値です。
- 小春六花の外見はユーザー提供の参照画像を基準にしています。製品同梱・公開配布前にキャラクター/IP利用条件と再配布可否を確認してください。
