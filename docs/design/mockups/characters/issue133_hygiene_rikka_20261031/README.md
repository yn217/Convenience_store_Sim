# Issue #133 小春六花：衣料品・衛生用品カテゴリモックアップ

衣料品と衛生用品のカテゴリ、専用フック棚、需要確認をまとめた商品管理画面案です。

## 対象

- 衣料品（靴下、レインウェア、手袋）と衛生用品（マスク、絆創膏、衛生用品）のカテゴリカード
- カテゴリ、専用棚、需要、導入条件を切り替えるタブ
- 商品カード、価格、売場サイズ、需要タグ、導入条件
- Issue #133 の初期フェーズとして、マスク・絆創膏などの衛生用品から開始する導線
- 店長向け案内役としての小春六花キャラクター

## 境界と安全配慮

- 静的なUIモックアップであり、商品マスタ、在庫、発注、棚配置、需要計算、保存・復元には接続していません。
- 商品名、価格、需要タグ、導入条件は画面検討用の例示値です。
- 実在の医薬品名・ブランド・パッケージは使用しておらず、医療助言や効能表示を行いません。
- 実装時は、衣料品・衛生用品のカテゴリ定義、販売制限、表示内容、地域ごとの法務要件を別途確認してください。

## キャラクターと権利

- 小春六花の外見はユーザー提供の参照画像を基準にしています。
- 製品同梱・公開配布前にキャラクター/IP利用条件と再配布可否を確認してください。
