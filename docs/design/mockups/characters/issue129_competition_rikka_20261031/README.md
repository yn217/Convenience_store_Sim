# Issue #129 小春六花：地域競争・経営対策モックアップ

近隣ライバル店の開店を地域ニュースとして伝え、影響、対抗策、日次比較を確認する画面案です。

## 対象

- 架空の周辺エリアマップと自店・ライバル店
- 近隣店の開店ニュース、影響期間、来店数・カテゴリ・夕方競合度の予測
- 競争状況、対抗策、日次比較のタブ
- 商品カテゴリ拡充、販促、レジ混雑改善、店内設備強化の対抗策カード
- 7日間の来店数・売上比較と、影響の主な要因
- 小春六花を地域競争の説明と施策選択の案内役として配置

## 境界と実装上の注意

- 静的なUIモックアップであり、MarketCondition、イベント発生、需要計算、セーブ・ロード、対抗策の効果適用には接続していません。
- ライバル店名、影響値、期間、費用、予測値は画面検討用の架空・例示値です。実在企業・統計は使用していません。
- 実装時は持続状態と日替わりイベントを分離し、来店数・カテゴリ係数・広告・フェアの二重適用を防いでください。
- 早期プレイの回復不能を避け、影響上限、段階導入、難易度、冪等イベントID、既存セーブ互換を別途設計してください。
