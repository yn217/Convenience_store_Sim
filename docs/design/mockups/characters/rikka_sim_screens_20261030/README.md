## 使い方

- 小春六花を店長/アシスタントの案内役として統一する。
- キャラクターは説明・比較・接客の文脈を補助し、候補カード、拡張計画、購入商品と満足度の情報を隠さない。
- 画像内の年齢、氏名、金額、能力、レベル、在庫、満足度、日付はモックアップ例示であり、実装値ではない。
- 既存のIssue本文、マスタ、Balance、Save/Load、Domain状態を正本とする。

## 境界と権利

これはレビュー用のPNGモックアップであり、Godot画面・操作・シミュレーションには接続していません。キャラクター画像はユーザー提供の小春六花参照に基づくため、正式採用・公開配布前にキャラクター/IPの利用条件と再配布可否を確認します。
