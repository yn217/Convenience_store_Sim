# Issue #115 小春六花：店頭・外構レイアウト設計モックアップ

屋外の静的装飾、配置候補、将来のゲーム効果候補を分け、歩道・入口・客/車の導線を確認する仕様提案画面です。

## 対象

- 店頭、歩道、入口、駐車場、道路、車両アクセスゾーンの上面レイアウト
- 静的装飾（植樹、フェンス、店頭プランター）
- 配置候補（自動販売機、ごみ箱、ベンチ）
- ゲーム効果候補（駐車スペース、充電設備）
- 選択オブジェクトの設置サイズ、設置可能ゾーン、導線への影響、保存/ロード、撤去費用
- 入口/歩道を塞がない、客と車の導線、既存レイアウト互換、効果未適用のチェックリスト
- 小春六花を仕様レビューの案内役として配置

## 境界と安全な扱い

- **仕様検討用の静的案であり、実際のゲーム画面・実装済み機能ではありません。**
- 屋外配置、来店効果、売上効果、駐車・充電収益、保存・撤去は未実装です。
- オブジェクトの状態は未承認/検討中/仕様レビュー待ちとして表示し、効果や費用をゲームに適用していません。
- 実装時は外構、入口、歩道禁止区画、客/車の導線、タイル footprint、既存セーブ互換を別途設計してください。
