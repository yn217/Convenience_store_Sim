## 実装に際しての注意
- **3案とも未承認・実装されていない参考画像**。UI配置と配色は参考にできるが、画像に描かれた数値・取引・時刻・称号は正本ではない。
- 参考となる元の営業結果スクリーンショットでは、売上 `¥210`、粗利 `¥80`、**営業利益 `-¥3,990`**、購入客 `1人`、廃棄 `¥0`。生成画像には**営業利益の負号欠落（`¥3,990`）、来店客の不一致（0人/1人）、未確定の時間軸・称号・評価スコア、存在しない営業イベント**などの誤描写があるため、実装値として使ってはいけない。
- 日次レポートの会計値は `DailyLedger` 等の**実ゲームの集計データのみ**から読み、売上・粗利・営業利益・現金残高を混同しない。0人/低売上の日や初日も正しく扱う。
- 購入客数・来店客数・客単価を定義に従い区別する。購入が1件あっても上部HUDが0人のまま表示される症状があるなら、その不整合も元データで検証する。
- UIは1280×720 / 1920×1080で文字が重ならず、店内の視認性、六花の立ち絵サイズ、ボタンのクリック領域、キーボードとゲームパッド入力、詳細/翌日への遷移を確認。
- イベント年表、初回称号、達成演出は**イベント履歴と実績の実状態**だけを表示し、架空の記録を追加しない。二重表示や二重付与を防ぐ。
- 素材利用・キャラクターIPおよび再配布条件は、正式採用前に確認する。
