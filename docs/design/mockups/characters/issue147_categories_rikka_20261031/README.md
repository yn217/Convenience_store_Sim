# Issue #147 小春六花：新カテゴリ・商品管理モックアップ

弁当、野菜・日配、カウンターコーヒーを、商品・設備・在庫・期限・立地別需要と一緒に確認する画面案です。

## 対象

- 弁当、野菜・日配、カウンターコーヒー、商品マスタの切り替えタブ
- 商品名、仕入価格、売価、期限、在庫、予想販売のカード
- 弁当棚、冷蔵ショーケース、コーヒーカウンターの設備・棚プレビュー
- 駅前・学校前・オフィス街・住宅地の立地別需要傾向
- 期限ロット、豆・カップ在庫、初回設備費、導入プラン
- 小春六花を新カテゴリ導入の案内役として配置

## 境界と実装上の注意

- 静的なUIモックアップであり、商品マスタ、仕入れ、補充、販売、廃棄、期限ロット、設備、日次決算には接続していません。
- 商品、価格、在庫、期限、予想販売、費用は画面検討用の例示値です。実在ブランド・ロゴは使用していません。
- 実装時は既存の期限ロット、棚在庫表示、価格、#148の立地需要を再利用し、未実装カテゴリの売上を計上しないでください。
- カウンターコーヒーは豆・カップ在庫と提供時間、設備費を分離して扱う前提です。

- 小春六花の外見はユーザー提供の参照画像を基準にしています。
- 製品同梱・公開配布前にキャラクター/IP利用条件と再配布可否を確認してください。
