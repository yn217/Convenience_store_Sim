# Issue #113 小春六花：レジ周辺密度モックアップ

レジ背面の業務什器、カウンター小物、店員演出、床の待機スペースを確認するための画面案です。

## 対象

- レジ台、コーヒーマシン、ホットスナック、袋詰め台、レシート端末
- 店員がレジに立つ通常営業演出
- 床に表示した待機位置と「待機 3人」
- レジ周辺の密度とクリック対象の整理

## 境界と権利

- 静的なUIモックアップであり、会計処理、客の経路、待機アニメーション、実際のクリック判定には接続していません。
- 待機人数、売上、来客数、店舗評価は画面検討用の例示値です。
- 小春六花の外見はユーザー提供の参照画像を基準にしています。製品同梱・公開配布前にキャラクター/IP利用条件と再配布可否を確認してください。
