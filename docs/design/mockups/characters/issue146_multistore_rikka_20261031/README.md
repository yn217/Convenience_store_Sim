# Issue #146 小春六花：店舗ネットワーク・出店計画モックアップ

複数店舗を地図上で管理し、出店候補、店舗規模、スタッフ配分、全店の経営状況を比較する画面案です。

## 対象

- 架空の市街地マップと既存店・出店候補のピン
- 駅前店・住宅地店などの店舗切り替えカード
- 選択中の出店候補の立地需要、競合、規模（小・中・大）、建設費、予想来客数
- 全店の合計売上、利益、来客数、共通資金
- 店舗ごとの立地・規模・スタッフ数・日次実績
- 小春六花を店舗展開と資金・スタッフ配分の案内役として配置

## 境界と実装上の注意

- 静的なUIモックアップであり、地図、複数店舗シミュレーション、出店処理、店舗切り替え、スタッフ異動、セーブ・ロードには接続していません。
- 地図、来客数、売上、利益、建設費、競合は画面検討用の架空・例示値です。実在の地理情報は使用していません。
- 実装時は店舗ごとの立地・規模・時間を保存し、非表示店舗の進行方式、共通資金、スタッフ所属を明示的に決めてください。
- 既存の立地（#148）、来店目的（#141）、店舗規模（#145）、ライバル商圏（#129）と責務を分離し、需要や売上を二重計上しないでください。
