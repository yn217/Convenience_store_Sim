# Issue #151 小春六花：観光・旅行需要管理モックアップ

観光地・ホテル・駅・観光バス停からの流入を、時間帯、旅行目的、在庫計画と一緒に確認する画面案です。

## 対象

- 架空の周辺エリアマップと、観光地・ホテル・駅・観光バス停の距離表示
- 観光地、ホテル、駅・帰路を切り替える需要予測グラフ
- 食べ歩き、ホテルの朝食/夜食、帰路のお土産、出張の軽食の旅行目的カード
- 観光向け商品棚の例（地域限定菓子、架空限定雑貨、充電用品、雨具、日焼け止め、飲料、サンドイッチ）
- 潜在来店と実入店、売場・在庫上限、観光向け棚の目安
- 小春六花を需要説明と品揃え確認の案内役として配置

## 制約と実装境界

- 静的なUIモックアップであり、観光需要係数、POI距離計算、在庫、売場、決済、混雑、セーブ・ロードには接続していません。
- すべて架空の地図・商品・数値です。実在の観光統計、企業、ブランド、決済APIは使用していません。
- UI・看板は既存の日本語表示のみです。多言語POP、翻訳ラベル、国籍や外見に基づく客層固定は扱いません。
- 実装時は#148の立地需要、#31イベント、#129ライバル、#136広告、#140フェアと観光流入を分離し、潜在来店と実入店、需要と売上を二重計上しないでください。
