# Issue #137 小春六花：販促・セール管理モックアップ

商品価格・値引き条件・販売期間・販促費・対象SKU/カテゴリを、媒体広告とは分けて管理する画面案です。

## 対象

- 販促カレンダー、企画作成、効果・実績の3タブ
- おにぎり均一価格デー、朝食セット、揚げ物＋飲料セット、次回来店クーポンの企画カード
- 対象カテゴリ/SKU、期間、割引方法、予想粗利、販促コスト、状態
- 期間中の企画を比較するカレンダーと、売上・粗利・ROIの予測パネル
- 架空POPプレビューと「販促を登録する」導線
- 小春六花を店長向けの販促ガイドとして配置

## 境界と実装上の注意

- 静的なUIモックアップであり、会計、在庫、クーポン発行・償還、保存・復元、販促費台帳には接続していません。
- 商品名、価格、期間、予想粗利、販促コストは画面検討用の架空例です。実在企業の企画・価格・日付はコピーしていません。
- 現MVPの「1訪問=1SKU/1個」を画面注記に残し、複数点セット割は複数点購入仕様の実装後に有効化する前提です。
- 実装時は基準価格・値引き後売価・原価・販促費・クーポン費用を分離し、二重計上を防いでください。
