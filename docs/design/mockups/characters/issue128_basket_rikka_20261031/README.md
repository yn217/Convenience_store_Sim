# Issue #128 小春六花：かご買い・客単価分析モックアップ

来店客数、購入客数、販売点数、客単価を分け、かご点数と会計負荷を確認する画面案です。

## 対象

- 日次サマリー、かご構成、会計負荷のタブ
- 来店客数、購入客数、販売点数、客単価のKPI
- 1点・2点・3点・4点以上のかごサイズ分布と平均点数
- おにぎり、飲料、サンドイッチ、菓子の予定・取得・寄り道構成
- 前日比較、会計時間の目安、基本時間と1点ごとの加算
- 取引ID、1点1行台帳、予約解放、旧セーブ読み込みの監査項目
- 小春六花をかご買いと混雑のバランス説明役として配置

## 境界と実装上の注意

- 静的なUIモックアップであり、basket_size RNG、購入処理、予約、会計、台帳、セーブ・ロードには接続していません。
- 点数分布、KPI、売上、会計秒数は画面検討用の例示値です。
- 実装時は来店客数・購入客数・販売点数・客単価を混同せず、1点1行台帳と共通取引IDを維持してください。
- 旧セーブは `basket_size=1` として読み込む互換方針、途中離脱時の全予約解放、同一seed再現を別途検証してください。
