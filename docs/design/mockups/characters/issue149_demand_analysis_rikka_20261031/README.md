# Issue #149 小春六花：客層・需要分析モックアップ

周辺施設・時間帯・来店目的による需要差を、統計グループとカテゴリ別実績で確認する画面案です。

## 対象

- 周辺施設：大学、ホテル、病院、駅、工場
- 客層の構成：学生、通勤客、宿泊客、観光客、近隣住民
- 時間帯別来店数
- 来店目的とカテゴリ別の売れ筋
- 店舗・日付・時間帯・周辺施設のフィルター

## 境界と権利

- 静的なUIモックアップであり、客層生成、需要モデル、実購入集計、保存・ロードには接続していません。
- 客層はゲーム内の統計グループであり、人物の外見・性別・年齢から属性を推定しません。
- 数値、施設、来店目的、売れ筋は画面検討用の例示値です。
- 小春六花の外見はユーザー提供の参照画像を基準にしています。製品同梱・公開配布前にキャラクター/IP利用条件と再配布可否を確認してください。
