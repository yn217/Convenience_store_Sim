# Issue #140 seasonal campaign character mockup

This is a review mockup for Issue #140, separate from the four character screens in PR #173. The current primary image uses the user-provided Koharu Rikka character reference.

## Screen intent

- Koharu Rikka is shown as the store manager/assistant introducing a spring campaign.
- The character supports the decision without covering the campaign controls.
- The screen exposes target products, novelty stock, campaign period, details, and start action.
- The campaign UI is fictional and uses no real company or product brand.

## Scope boundary

This PNG is a visual proposal only. It does not implement campaign state, inventory, ledger effects, seed handling, or Godot controls. The displayed date, stock count, products, and labels are illustrative; runtime values must come from the Issue #140 campaign model and existing product data. The character identity is user-specified; redistribution and formal character/IP approval remain open before production use.

## Validation

- 1672x941 RGB PNG.
- Character is confined to the left presentation area; primary controls remain visible.
- No title screen, title-return menu, staff recruitment, customer detail, store expansion, or achievement layout is included.
- `seasonal_campaign_character_mockup_generic_v01.png` preserves the previous generic-character draft for comparison.
