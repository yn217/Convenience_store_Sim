# Issue #31 小春六花：本日の地域イベントモックアップ

日替わりイベントの選択結果、期間、需要効果、イベント履歴、保存状態を確認する画面案です。

## 対象

- 今日のイベント、イベント履歴、効果の内訳のタブ
- 選択中イベントのタイトル、状態、期間、イベントなしとの比較効果
- 地域祭り、近隣工事、気温変化、軽食人気、口コミ、学校行事など12種類の候補一覧
- イベントID、独立RNG、既読、CLOSE→OPEN再抽選なし、SAVE/LOAD復元
- 効果の適用期間と、広告・価格・立地倍率との二重計上防止注記
- 小春六花を仕入れ・スタッフ配置の案内役として配置

## 境界と実装上の注意

- 静的なUIモックアップであり、EventDirector、抽選、需要倍率、日界、保存・復元、通知には接続していません。
- イベント名、期間、効果値、イベントID、RNGは画面検討用の例示値です。実装時はIssue本文・仕様書・seed JSONを正本としてください。
- 日替わりイベントは1日最大1件（noneを含む）とし、広告・価格・立地・持続状態と効果を二重適用しない前提です。
- 未実装の天気、従業員、複数商品購入システムを画面から追加しません。
