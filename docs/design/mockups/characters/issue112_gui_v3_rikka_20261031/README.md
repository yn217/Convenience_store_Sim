# Issue #112 小春六花：GUI v3表示ルール・プレビューモックアップ

一体型トップバー、大きい左ナビ、下部HUD、カタログ/インスペクタを同じ画面で確認し、表示情報の優先度と安全余白をレビューする画面案です。

## 対象

- 一体型トップバーと大きい左ナビ
- 店舗ビューを覆わない下部HUD（目標、KPI、イベントタイムライン）
- 商品カタログ、カテゴリピル、価格行、選択中商品のインスペクタ
- 常時表示と選択/ホバー時のみ表示の分類
- 棚・右下アラートを隠さない、1280×720/1920×1080で文字切れなし、速度倍率でも操作可能なチェック
- 小春六花をUI表示ルールの案内役として配置

## 境界と実装上の注意

- 静的なUIモックアップであり、GodotのGUI、操作判定、カメラ、サムネイル接続には未接続です。
- 商品名、価格、売上、客数、時刻は画面検討用の例示値です。未実装の指標や天気を追加していません。
- 商品サムネイルは仮の表示例であり、#91/#102の正式採用素材が来た時点で差し替える前提です。
- 実装時は#89/#105/#109/#110/#117と責務を分け、ラベル過多で棚・人物・重要警告を隠さないでください。
