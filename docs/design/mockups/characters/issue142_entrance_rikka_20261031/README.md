# Issue #142 小春六花：来店・入口混雑モニターモックアップ

店外の歩道からの来店、入口判定、入店・引き返し、通行人、レジ列の影響を確認する画面案です。

## 対象

- 架空の店舗外観、歩道、入口、通行人、来店客
- 来店、入店、混雑で引き返しの状態タグ
- 潜在来店、実入店、混雑で引き返し、通行人のKPI
- 開いているレジ、列人数、列容量、最短待ち時間、引き返し判定
- 接近→入口判定→入店/引き返し→歩道への流れ
- 混雑で入店をあきらめた客の日次レポートと評判影響
- 小春六花を混雑対策の案内役として配置

## 境界と実装上の注意

- 静的なUIモックアップであり、歩行経路、入口位置、レジ列、来店判定、セーブ・ロード、日次評判には接続していません。
- 来店数、列人数、待ち時間、引き返し人数は画面検討用の例示値です。大量スポーンや高速移動を前提にしていません。
- 実装時は潜在来店・実入店・通行人・引き返しを分離し、入口判定をレジ容量・待ち時間・稼働レジ数と整合させてください。
- 既存の外構（#110）、入口位置（#121）、スタッフ/レジ（#143）、来店目的（#141）と責務を分離します。
