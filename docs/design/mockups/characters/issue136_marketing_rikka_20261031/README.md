# Issue #136 小春六花：販促キャンペーン計画モックアップ

媒体別の広告・販促を、目的・対象・予算・期間・効果予測で比較する画面案です。

## 対象

- 「地域紙」「テレビCM」「ラジオCM」「ネット広告」の媒体カード
- 目的、対象カテゴリ、時間帯、予算、実施期間
- 想定リーチ、来店数への影響、広告費、予測粗利益
- 「予測値。実績は営業後に確認できます」の表示
- 出稿確定の操作位置

## 境界と権利

- 静的なUIモックアップであり、媒体別広告ロジック、請求、効果適用、保存・復元には接続していません。
- 媒体名、費用、リーチ、効果、粗利益は画面検討用の例示値です。実在企業・媒体のロゴは使用していません。
- 小春六花の外見はユーザー提供の参照画像を基準にしています。製品同梱・公開配布前にキャラクター/IP利用条件と再配布可否を確認してください。
