# Issue #105 小春六花：通常営業メイン画面モックアップ

通常営業中の店舗画面に、Issue #105で指定されたHUD・下部目標・イベント・客単価・カテゴリ表示をまとめた検討用モックアップです。

## 対象

- 時刻・季節・資金・売上・来客数・店舗評価の上部HUD
- 左ナビゲーションと商品発注などの下部ショートカット
- 「本日の状況」「人気商品 TOP5」
- 「本日の目標」「本日のイベント」
- 客単価とカテゴリピル（おにぎり、弁当、飲料、菓子など）

Issue #105の非対象に合わせ、スタッフ管理専用画面や天気・リピート率は入れていません。

## 境界と権利

- 静的なUIモックアップであり、Godotの実行画面、実データ更新、入力、ホバーには接続していません。
- 売上、来客数、客単価、商品数、目標、イベントは画面検討用の例示値です。
- 小春六花の外見はユーザー提供の参照画像を基準にしています。製品同梱・公開配布前にキャラクター/IP利用条件と再配布可否を確認してください。
