# Issue #134 小春六花：イートイン管理モックアップ

購入済みのお客様が短時間滞在するイートインスペースを、座席状況・配置・清掃の3視点で管理する画面案です。

## 対象

- テーブル、カウンター席、ごみ箱、トレイ返却台
- 「空席 3 / 8席」「食事中」「退席待ち」「清掃待ち」
- 「配置を変更」「清掃する」の操作位置
- 購入後の着席であり、再会計が発生しないことの案内

## 境界と権利

- 静的なUIモックアップであり、着席経路、席占有、退席、清掃、セーブ・ロード、4倍速QAには接続していません。
- 座席数、滞在状態、効果、設備名はIssue #134の画面検討用の例示値です。
- 小春六花の外見はユーザー提供の参照画像を基準にしています。製品同梱・公開配布前にキャラクター/IP利用条件と再配布可否を確認してください。
