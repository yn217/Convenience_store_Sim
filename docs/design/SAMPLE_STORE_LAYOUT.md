# サンプル店舗レイアウト（sample_store_v1）

デモ・スクリーンショット・性能計測（tools/capture_screen.gd, tools/perf_bench.gd）で使う店内配置の設計メモ。ゲームデータ（什器定義・経済・初期状態）は変えない。配置の正本は `data/layouts/sample_store_v1.json`。

## マップ（16×12、x=列 0〜15、y=行 0〜11）

y=0 が奥（北壁）、y=11 が出入口（南壁）。

```
      x 0123456789ABCDEF   (A=10 ... F=15)
y=0   ...DDDDDDDD.....
y=1   ...............o
y=2   ....nn......sg.o
y=3   ....nn......sg.o
y=4   ....ss......b..o
y=5   ....ss......b..t
y=6   ....gg.........t
y=7   ....gg.........b
y=8   ...........W...b
y=9   ...........R.II.
y=10  ...........R.II.
y=11  ........==......
```

## 配置の理由（実際のコンビニの計画原則）

1. **飲料の冷蔵ケースは奥（出入口から最も遠い壁）に並べる。** 客は店の奥まで歩いて飲料を取るので、店内を回遊させる「奥の引力」になる。4 基を 1 本の連続した列にして、y=1 の通路から一括して取れるようにした。
2. **レジは出入口のすぐ横、売り場に対してレジ側を向ける。** レジ (11, 9〜10) は出入口 (8〜9, 11) の斜め前にあり、客は入店してすぐ会計の列を見られる。レジの売り場側（x=10）は会計待ちの列と通路に使うため空けてある。
3. **衝動買いの商品はレジの近くに置く。** おでん什器 (11, 8) はレジの真上にあり、アイス (13〜14, 9〜10) はレジの隣。レジ待ちの客が手に取りやすい。
4. **中央は平行なゴンドラ通路。** 2 列の棚を背面合わせにした 2 本のゴンドラ（A と B）で、どの通路からも両面の商品が見える。出入口からの主動線は x=8〜9 を奥まで一直線に進み、奥の飲料ケースに届く。通路幅は最小 1 タイル以上（主動線は 2 タイル）。
5. **東壁は冷蔵ゾーンにまとめる。** おにぎり棚 2 基・デザートケース・パン棚を連続させ、レジ側の壁に寄せた。客がまとめて選べて、補充も一箇所で済む。
6. **窓側は開けておく。** 南側の窓沿い（y=10〜11）は雑誌棚がないため通路のままにした。出入口の前のタイル (8,10), (9,10) は何も置かない（配置ルールでも禁止）。
7. **すべての取り出し面は通路に面する。** 各什器のアクセスタイルは到達可能で、テスト（tests/unit/test_sample_layout.gd）で全什器について確認している。

## 注意

- レイアウトの見た目を変えるときは、出入口から各什器のアクセスタイルまで歩けることを必ず確認する（テストが失敗する）。
- 性能計測の条件は「16×12・什器 20 基・客 30 人・1920×1080・×1/×2/×4」。旧配置は 16 基しか置けていなかったため、配置数は変わる（記録は docs/qa/MVP_ACCEPTANCE_RESULTS.md）。
